
# Moyo Landing Page

A responsive landing page for the Moyo online store.

## Demo

- [Live Demo](https://annavas03.github.io/Landing_Moyo/)
- [Figma Design](https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f)

## Technologies Used

- HTML5
- SCSS

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/annavas03/Landing_Moyo.git
   cd Landing_Moyo
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

## Features

- Responsive layout for screen widths of 320px, 744px, and 1260px.
- Sticky header that remains visible while scrolling.
